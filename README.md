
#  Hospital Management Project

A comprehensive, web-based Hospital Management System built as a 3rd Semester, 2nd Year academic project. This system is designed to streamline hospital operations by providing dedicated dashboards and functionalities for different roles within a healthcare facility.

## Features

The system includes specialized modules and dashboards for various users:
*   **Admin Panel:** Complete control over hospital operations, staff management and system monitoring (`admin-dashboard.html`).
*   **Doctor Dashboard:** Features for doctors to manage their schedules, view patient details and access medical records (`doctorDashboard.html`).
*   **Nurse Dashboard:** Dedicated portal for nurses to manage patient care, tasks and daily reports (`nursedashboard.html`).
*   **Staff Dashboard:** A portal for general hospital staff to handle administrative and logistical tasks (`staffdashboard.html`).
*   **Patient Portal:** Allows patients to register, view their health records, and interact with the system (`patientDashboard.html`).
*   **Department & Services:** Informational pages for Ambulance, Blood Bank, Clinic, Emergency, Insurance, Lab and Nutrition (`ambulance.jpg`, `blood.jpg`, `clinic.jpg`, etc.).
*   **User Authentication:** Separate login pages for Admin, Doctor, Nurse, Staff, and Patients.

##  Technologies Used

*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
*   **Backend / Logic:** Python (`task.py`)
*   **Assets:** JPG, WEBP (Icons and UI images)
*   **Tools:** Git, GitHub

##  Project Structure

Here is a brief overview of the key files in the repository:
*   `index.html` - The main landing page of the hospital website.
*   `*.html` - Various functional pages (dashboards, login pages, department info).
*   `*.js` - JavaScript files handling the logic and interactivity for each dashboard.
*   `style.css` - The main stylesheet for the entire application.
*   `task.py` - Python script (likely used for backend logic, database seeding, or specific hospital tasks).
*   `*.jpg / *.webp` - Images and icons used throughout the UI.
